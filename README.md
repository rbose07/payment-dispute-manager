# Payment Dispute Manager

⚠️ Vulnerable Spring Boot application intentionally created for OWASP Top 10 demonstrations.

## Purpose

This project simulates a payment dispute management platform used by payment processors and banks.

## Included Vulnerabilities

- Broken Access Control
- SQL Injection
- Sensitive Data Exposure
- Authentication Failures
- Insecure File Upload

## Disclaimer

This project intentionally contains security vulnerabilities and must never be deployed to production.
